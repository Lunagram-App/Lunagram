# Lunagram

Неофициальный клиент Telegram для Android. Этот репозиторий предназначен для общедоступных сборок Lunagram.

## Скачать

[Сайт Lunagram](https://lunagram.matveidrugmoi.chatgpt.site/) · [Опубликованные версии](https://github.com/Lunagram-App/Lunagram/releases)

В составе релиза публикуются общий APK для ARM64, контрольные суммы SHA-256 и архив соответствующих исходников с инструкцией сборки. Личные сборки здесь не распространяются.

## Проверка файлов

Сверяйте имя файла и его SHA-256 с данными релиза. Не отключайте проверку подписи Android и не передавайте никому коды входа в Telegram. Контрольная сумма подтверждает совпадение файла, но сама по себе не гарантирует отсутствие ошибок или уязвимостей.

## Исходники

Lunagram основан на Telegram для Android. В архиве исходников сохраняются исходные лицензии и сведения об авторах. Ключ подписи, локальные настройки и служебные учётные данные в публичный архив не включаются.
